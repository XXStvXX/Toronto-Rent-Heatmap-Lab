# AI-Assisted Workflow

This project uses AI as a development assistant, not as an authority.

AI-assisted work was useful for:

- comparing project structure options
- drafting and tightening documentation
- generating implementation ideas for ETL, validation, and dashboard workflow notes
- identifying edge cases and limitations to review manually
- preparing recruiter-readable explanations

Human validation remains the core of the project:

- data-source assumptions must be checked against official documentation
- cleaning and geography-matching logic must be reviewed manually
- outputs need tests, screenshots, and source-backed findings
- limitations must remain explicit, especially around aggregate geography data

The portfolio goal is to show a modern analyst workflow:

```text
AI-assisted prototyping -> human validation -> documented analytics product
```

AI helped speed up iteration, but the final reasoning, assumptions, limitations, and interview explanation are owned by the author.
