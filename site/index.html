Practical rendering choice: no pan/zoom, no OpenStreetMap tiles, one fixed SVG, six regional polygons, fixed Toronto extent. This keeps GitHub Pages fast and still useful for comparing areas.

The repository keeps the SQL and Power BI path for real CMHC or Toronto Open Data imports. This front page is the lightweight deployed product view.

Select a regionHover over a region to inspect rent, vacancy, and estimated sample size.
The shape is intentionally regional, closer to a Power BI shape map than Google Maps. That is the right tradeoff for a GitHub Pages dashboard.
